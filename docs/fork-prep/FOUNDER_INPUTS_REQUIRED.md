# Founder Inputs Required

## Purpose

This page separates the few founder-only decisions from the many execution tasks that can continue autonomously.

## Why This Exists

The fork can keep progressing without constant founder involvement, but a few decisions should not be guessed by implementation tools.

## Required Before Full Rename Pass

### Brand Identity

- Final product name
- Short slug
- Package scope
- Desktop protocol
- Primary domain

### Platform Identity

- Windows app ID
- macOS bundle ID
- preferred release artifact naming

## Required Before Production-Like Infra

### Provider Choices

- Supabase project owner/account
- AI provider choice
- Billing provider choice
- analytics provider choice
- email provider choice
- release host choice

### Trust / Product Choices

- whether billing is in early baseline or stubbed
- whether shared corpus is considered part of the MVP
- whether web companion is in active scope
- whether landing page is in active scope

## Required Before Shared Corpus Work

- opt-in vs default
- user-private vs centralized boundary
- acceptable data fields for centralized ingestion
- trust/privacy posture

## Required Before Public Launch

- pricing
- legal review
- privacy/consent language
- launch scope
- support/contact path

## Everything Else Can Largely Keep Moving

Without these decisions, AI can still do:

- repo prep
- scope reduction
- provider/env mapping
- schema planning
- extension seams
- baseline runbooks
- GitHub/Linear/Notion setup
- parser/source audits
- contributing/workflow docs
