# Notion Pack

This folder contains an import-ready starter pack for the project workspace in Notion.

Suggested top-level Notion pages:

- Home
- Product
- Strategy
- Architecture
- Research
- Execution
- Decision Log

Suggested import order:

1. `01-Founder Ops.md`
2. `02-Project Overview.md`
3. `03-Product Brief.md`
4. `04-Core Acquisition Plan.md`
5. `05-Inherited Core vs New Moat.md`
6. `06-System Overview.md`
7. `07-Data Model.md`
8. `08-Ranking and Filtering Design.md`
9. `09-Shared Corpus Strategy.md`
10. `10-Trust Privacy Consent Notes.md`
11. `11-LLM Role Guide.md`
12. `12-Weekly Ops Template.md`

Database/template file:

- `decision-log-template.csv`

Recommended workflow:

- Import the Markdown files as pages
- Create the top-level page groups manually
- Move each imported page under the right top-level section
- Import `decision-log-template.csv` as a table database
