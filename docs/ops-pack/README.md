# Ops Pack

This folder contains copy/paste templates for Linear and GitHub setup.

Contents:

- `linear-projects.md`
- `linear-first-epics.md`
- `linear-ticket-template.md`
- `github-labels.md`
- `github-milestones.md`
- `github-issue-template.md`
- `github-pr-template.md`

Suggested usage:

1. Create the Linear projects from `linear-projects.md`
2. Add the initial epics from `linear-first-epics.md`
3. Save `linear-ticket-template.md` somewhere your team can reuse
4. Create GitHub labels from `github-labels.md`
5. Create GitHub milestones from `github-milestones.md`
6. Add the issue and PR templates to your repo
